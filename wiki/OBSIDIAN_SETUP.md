# Obsidian Vault Setup
Open the repository's `wiki/` folder as an Obsidian vault. Enable `imperial-codex.css` under Settings → Appearance → CSS snippets. Use graph view, backlinks, and search to navigate the interlinked Markdown pages. The original source files remain outside the vault in their existing repository locations; links to them are ordinary relative Markdown links.

The GitHub Pages browseable codex lives in `docs/codex/`. The vault is the editable, version-controlled knowledge base; the Pages site is the public reading experience.
