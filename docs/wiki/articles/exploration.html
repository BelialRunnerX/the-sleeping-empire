Exploration and recovery

Native development snapshot · Reviewed 18 November 2026

The home waypoint guides travel; the separate camp anchor can influence death recovery. Neither is a general teleport system.

Version matters. This is an implementation reference, not a promise that every feature is in your installed build. Provisional adaptations and limitations are stated explicitly. Controls describe the documented native snapshot and may differ in the Windows GUI handoff.

Home waypoint

F6 marks one home waypoint under the documented grounded safety checks. It provides direction, horizontal range and relative height on the same face. It is guidance only, not a respawn or transport command.

Camp anchor

F9 marks a separate native camp; Shift+F9 clears it. Marking requires a living player, known support and a clear dry body volume outside gated modes/panels. Marking does not heal, grant equipment, reset cooldowns or move the character.

Recovery validation

After death, the saved exact feet position is used only if current same-face geometry still validates. Obstructed or invalid camps fall back to the existing origin-grounding behavior. No downward search silently moves the camp. Geometry validity does not guarantee safe atmosphere, temperature or enemies.

Dash

The native dash is a bounded collision-checked movement adaptation. It does not add invulnerability, damage or a paid mana resource. It preserves the existing vertical-motion policy; movement and landing behavior must not be mistaken for a new combat authority.
