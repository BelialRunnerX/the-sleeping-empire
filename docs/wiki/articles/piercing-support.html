Pierce: trading damage for targets

Native snapshot · Reviewed 19 November 2026

Pierce is a saved support for the basic pulse, independent of the radial support selection.

Version matters. This is an implementation reference, not a promise that every feature is in your installed build. Provisional adaptations and limitations are stated explicitly. Controls describe the documented native snapshot and may differ in the Windows GUI handoff.

Native snapshot

Tradeoff

Pierce reduces per-target damage to 85% before rounding and permits up to three distinct target opportunities per shot. None keeps the ordinary single-target pulse. The documented native bag shortcut is Shift+N.

Native snapshot

Aim through a group, not a wall

Targets are encountered in flight order. Each target can be attempted only once by that shot. A wall or occluded selected target ends the remaining flight. Pierce does not ignore terrain or revisit the same enemy.

Native snapshot

Choosing a support

Pierce is useful when enemies line up; None avoids the damage tradeoff when you need one target down quickly. This is a practical interpretation of the current rules, not a claim of mathematically optimal damage in every encounter.
