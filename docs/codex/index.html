A mechanics reference for Elysium, a sci-fi solarpunk voxel action RPG with survival, crafting, automation and colony systems.

Version matters. This is an implementation reference, not a promise that every feature is in your installed build. Provisional adaptations and limitations are stated explicitly. Controls describe the documented native snapshot and may differ in the Windows GUI handoff.

Native snapshot

What this wiki covers

This edition describes the native development snapshot, with a separate label for design goals and browser reference material. It is not a claim that every system is available in a released Windows build. The native game and the older browser adaptation are different implementations; their saves, controls and formulas must not be mixed.

Native snapshot

The core loop

Explore and mine a destructible world, turn resources into useful equipment and machines, fight hostile encounters, and build a base that supports further exploration. Durable progression, loot and ordinary world simulation have different save boundaries.

Native snapshot

Reading status labels

Native snapshot means the cited native source documents describe implemented behavior. Native adaptation means a bounded implementation differs from donor rules or uses provisional balancing. Planned means a design intention, not a playable promise. Every article identifies its source and limitations.
